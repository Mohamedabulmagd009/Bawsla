# بوصلة | Bawsala — Landing Page

تحويل تصميم Figma (`Bosla`) إلى كود. صفحة عربية RTL متجاوبة مع كل الشاشات.

## الهيكل
```
bawsala/
├── index.html          ← نسخة HTML
├── css/style.css       ← الـ CSS (مشترك بين HTML و React) وفيه توكنز الديزاين سيستم
├── js/main.js          ← الـ JavaScript (بدون مكتبات)
├── react/index.html    ← نسخة React في ملف واحد (React 18 + Babel من CDN)
└── images/             ← الصور المستخدمة في التصميم + README-images.md
```

## التشغيل
- **HTML:** افتح `index.html` مباشرة في المتصفح.
- **React:** افتح `react/index.html` (محتاج إنترنت لتحميل React والخط). للمشروع الحقيقي انقل الكود
  اللي جوه `<script type="text/babel">` إلى مشروع Vite/Next كما هو.
- لو عايز سيرفر محلي: `npx serve .` من داخل الفولدر.

## الالتزام بالديزاين سيستم
كل القيم في أول `css/style.css` مأخوذة من Variables في Figma:
Primary 50–950 وNature 50–950 وSuccess/Error/Warning، المسافات 4–80، الـ Radius (Button 20/24/28، Card 20/24/28،
Nav وFooter 40، Textbox 24)، أحجام الأزرار 40/44/48، التأثيرات (Drop + Inner)، والخط IBM Plex Sans Arabic
بمقاسات Display 48 وH1 40 وH2 32 وH3 24 وTitle 20 وSubtitle 16 وLabel 14.
الشاشات الصغيرة بتقلّل الخطوط تلقائيًا بـ `clamp()`.

## نقاط التوقف
`≥1200` ديسكتوب كامل · `1000–1199` أضيق · `<1000` القائمة تتحول لزر · `<900` الأقسام تتكدّس ·
`<560` عمود واحد للباقات · `<480` أزرار بعرض كامل.

## الأنيميشن
دخول الـ Hero بتتابع واحد، ظهور الأقسام عند التمرير، دخول صور المحطات وأرقامها، حركة الصورة الرئيسية،
حركة الأزرار والكروت عند الـ hover، شريط التقدم في التقييم. كل ده بيتعطل تلقائيًا مع
`prefers-reduced-motion`.

## ما هو تفاعلي
التقييم التجريبي (٣ أسئلة + مؤقت ٣٠ ثانية + نتيجة)، القائمة في الموبايل، تمييز الرابط النشط أثناء التمرير،
نموذج التواصل (تحقق + رسالة نجاح)، تسجيل الاهتمام في البرامج، اختيار الباقة. **مفيش خادم**:
تسجيل الدخول والمرشد الذكي وإرسال النموذج محاكاة فقط وجاهزة للربط بالـ API.

## التعديلات اللي عملتها على المحتوى (أخطاء في التصميم)
1. «مرشد مسار» و«masar.example.sa» ← «مرشد بوصلة» و«bawsala.example.sa» (تعارض اسم المنتج).
2. «٤٠ كريديت هدية» في قسم البرامج ← «٢٠» (باقي الصفحة بتقول ٢٠).
3. «١٤ أسابيع» ← «١٤ أسبوعًا».
4. تاريخ بداية البرنامج المميز «٢٠٢٦/١١/٠١» (فات) ← «٢٠٢٦/١١/٢٢» (أحد قادم، يتماشى مع جلسات الأحد والثلاثاء). **راجعه.**
5. الخطوة الثالثة في «كيف يعمل الكريديت» كان عنوانها مكرر «اشترِ حزمة كريديت» ← «استرد كريديتك تلقائيًا».
6. «اسأل مستشارك الآن» ← «اسأل المرشد الآن» (نفس اسم المرشد في باقي الصفحة).
7. إملاء: الاسعار→الأسعار، ارسال→إرسال، أختر→اختر، مجانا→مجانًا، مبيعا→مبيعًا، «الرياض , المملكة»→«الرياض، المملكة»،
   «© بوصلة٢٠٢٦»→«© ٢٠٢٦ بوصلة»، «١٥%»→«١٥٪».
8. الباقات المدفوعة كان مكتوب فيها «كريديت هدية» ← «كريديت» (الهدية للباقة المجانية فقط، والاحترافية فيها ١٠ هدية).
9. كروت الباقات كانت بزوايا حادة في Figma ← أخدت Radius 28 من الديزاين سيستم.
10. شعارات الشركاء اتوحّدت في صندوق بنفس الارتفاع بدل ما كل شعار في مكان مختلف.

## محتاج قرارك (ما غيّرتهوش)
- باقة «المتقدمة» مكتوب فيها «الأوفر لكل كريديت» لكن ٢٩٩ ر.س لـ ٣٠٠ كريديت (≈ ٠٫٩٩٩ ر.س للكريديت) هي الأغلى للوحدة؛
  الاحترافية (≈ ٠٫٨١) هي الأوفر.
- سؤالا التقييم ٢ و٣ كتبتهم أنا (التصميم فيه السؤال الأول بس).
- الرقم `1000` في رسمة الـ Hero بأرقام لاتينية وهو جزء من الصورة نفسها.
