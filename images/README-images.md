# صور تصميم بوصلة

تستخدم الصفحات الصور الموجودة في هذا المجلد مباشرةً. أسماء الصور مرقّمة حسب ترتيب المحطات في قسم «كيف تعمل»، بينما ملف `hero section.png` هو صورة قسم Hero.

| الملف | الاستخدام |
|---|---|
| `hero section.png` | صورة قسم Hero |
| `1.png` | محطة اكتشف |
| `2.png` | محطة قيّم |
| `3.png` | محطة خطّط |
| `4.png` | محطة تدرّب |
| `5.png` | محطة تقدّم |
| `6.png` | محطة تطوّر |
| `Athr.png` | شعار أثر |
| `Holol.png` | شعار حلول |
| `Nusuk.png` | شعار نسق |
| `Bayan.png` | شعار بيان |
| `Roaya.png` | شعار رؤية المستقبل |
| `Rayada.png` | شعار ريادة |
